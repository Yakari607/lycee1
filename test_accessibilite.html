❌ Test 1: Navigation au clavier et focus

Critères RGAA: 10.7, 12.8, 7.3

Résultat: ÉCHEC - Éléments critiques manquants

Problèmes détectés:

  • ❌ Aucun style :focus défini dans les CSS
  • ❌ Pas de liens d'évitement
  • ❌ Menus déroulants non accessibles au clavier
  • ❌ Attributs ARIA manquants sur les dropdowns
Code problématique détecté:
❌ .dropdown-menu { /* Manque aria-expanded, keydown events */ }
❌ Aucun :focus-visible ou :focus défini
❌ onclick="return false;" sans gestion clavier
Corrections requises:
• Ajouter des styles :focus visibles
• Implémenter la navigation clavier (Enter, Espace, Échap)
• Ajouter aria-expanded, aria-haspopup
• Créer des liens d'évitement

❌ Test 2: Accessibilité des formulaires

Critères RGAA: 11.1, 11.2, 11.10

Résultat: ÉCHEC - Formulaires non conformes

Problèmes détectés:

  • ❌ Aucun élément <label> associé aux champs
  • ❌ Utilisation exclusive de placeholders
  • ❌ Pas de gestion d'erreurs accessible
  • ❌ Champs obligatoires mal identifiés
Code problématique détecté:
❌ <input type="text" placeholder="NOM & PRÉNOM *" required>
❌ Manque: <label for="nom">Nom et Prénom</label>
❌ Manque: aria-describedby pour les erreurs
Corrections requises:
• Ajouter des <label> explicites avec for/id
• Remplacer les placeholders par des labels
• Ajouter aria-required="true"
• Implémenter la gestion d'erreurs avec aria-describedby
